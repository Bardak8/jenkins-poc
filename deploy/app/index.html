Architecture

Jenkins tourne sur un cluster Kapsule (Scaleway), reconstruit entièrement via Terraform + Helm + JCasC. Il pilote un second Terraform (provider Proxmox) pour provisionner des VM sur un VPS OVH, relié par tunnel WireGuard.

Pipelines

Cette page est servie par un Traefik + un conteneur nginx, déployés par le pipeline deploy-app depuis Jenkins.
